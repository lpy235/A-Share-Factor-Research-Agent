## Project Pitch

An A-share factor research agent for quant strategy research workflows.

It supports:

```text
Agent-collected public materials
User-provided materials
Factor hypothesis extraction
Restricted Factor DSL generation
A-share daily data validation
IC / RankIC / ICIR
Grouped returns
Long-short backtests
Factor selection and combination
Traceable Markdown research reports
```

## Non-Negotiable Boundaries

The project must not:

```text
Provide investment advice
Recommend stocks
Execute trades
Scrape paywalled or login-required materials
Scrape CNKI
Use Wind / Choice data without user-provided legal access
Run arbitrary LLM-generated Python code
```
