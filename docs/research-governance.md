# 日频因子研究治理基线

## 系统边界

系统用于日频 A 股因子研究、因子库管理和研究决策记录，不包含订单、券商、自动交易或交易执行模块。

## 数据规则

- 原始市场数据必须保存不复权价格和独立公司行为事件。
- 每次研究必须记录 `data_version`、数据来源、采集时间和数据 manifest 哈希。
- 非测试模式下，未发布数据版本不得用于因子入库决策。
- 数据源优先级为：内部授权导出或人工复核的 GitHub 数据快照、其他可审计文件导入。第一版不依赖 AKShare 或其他在线接口，也不把系统设计成每日抓取外部网站。
- GitHub 快照入仓前必须记录仓库地址、提交哈希或 Release 标签、文件哈希、覆盖期间、字段口径、许可证和复核结论；通过校验后才写入本地版本化数据仓。

## 回测基线

- 信号在交易日 t 收盘后形成；在 t+1 开盘建仓；收益按 t+1 开盘至 t+2 开盘计算。
- 默认成本为双边佣金 3 bps、卖出印花税 5 bps、双边滑点 5 bps；每次实验必须记录实际采用值。
- 因子必须同时通过 DSL、安全、数据覆盖、样本外、walk-forward 和成本后表现检查。

## 入库基线

- OOS Rank IC 与 IS Rank IC 方向一致，且绝对值不少于 0.01。
- walk-forward 数据充足、方向一致，且正 IC 窗口比例不少于 60%。
- 已入库因子必须保留来源证据、因子版本、实验版本、决策理由和相近因子比较。
- 基金经理 Agent 默认只给出建议；入库、降级和淘汰由人工确认并保留理由。

## 资源预算

- 单次研究任务默认只允许一个并发运行。
- 研究 Agent 的候选数、变形轮数、LLM 调用数和回测次数必须在任务开始时记录并受限。
- 在原始数据版本和因子库稳定前，不启动无边界的 7x24 自主裂变。
