# A 股原始日频数据源决策记录

**记录日期：2026-07-25**

## 决策结论

当前不批准任何公开 GitHub 仓库直接作为全 A 股历史数据基线。第一份正式基线应来自公司内部授权导出，或来自可明确授权、可固定提交/Release、可复核原始不复权口径的文件快照。

在拿到该快照前，只进行两只股票、一年期的受控 CSV 演练；不启动全市场 8 至 10 年回填，也不把在线接口响应直接写成“生产历史库”。

## 评价标准

候选源必须同时满足以下条件才可进入基线验收：

1. 可以固定到具体 Git 提交、Release 或内部导出批次；
2. 覆盖范围、字段定义、日期范围和许可证可审计；
3. 原始日线明确为不复权，或提供可复核的原始价与公司行为；
4. 能保留来源、文件哈希和导入时间，不依赖运行时在线查询；
5. 允许低成本地补齐日增量并与历史基线分版本管理。

## 已核对候选

| 候选 | 结论 | 依据与限制 | 可用边界 |
| --- | --- | --- | --- |
| 公司内部授权导出 | 优先，等待取得样本 | 可明确合同或内部权限、导出日期和字段口径 | 首选正式基线来源 |
| GitHub 可审计历史快照 | 暂无通过项 | 本轮公开检索未发现同时满足许可、全量历史、原始不复权与版本固定条件的仓库 | 继续作为补充检索方向 |
| `bzcsk2/daily_stock_data` | 不作为历史快照 | README 明确仓库不含个人数据库、dump 或完整历史运行数据；其数据源说明还表明当前日线没有逐行 `source`，并使用 baostock `adjustflag="3"` | 只可参考采集脚本、CSV/数据库运维方式；若使用其导出，必须重建血缘并单独复核复权口径 |
| `1nchaos/adata` | 不作为正式源 | 项目是公开网站的多源在线接口封装，不提供固定离线历史快照；响应会随上游服务变化 | 只可作两标的交叉核验或临时开发，不直接入正式库 |

本次核对的候选提交仅用于可重复地复查仓库文档，并不代表数据版本：

```text
bzcsk2/daily_stock_data  e0efc471e5350e08c58018cb49ba0e215cf1fb92
1nchaos/adata             b14f4e57b2175302f18b6eaf934f7dff9207a141
```

## 最小可行执行路径

1. 从内部或已授权渠道取得两只股票、一个完整自然年的原始不复权 CSV。
2. 记录提供方、导出时间、文件 SHA-256、许可证或授权说明、字段字典和复权声明。
3. 按 [原始日频数据基线运行手册](market-data-baseline-runbook.md) 导入草稿版本、通过质量门禁并发布。
4. 使用发布后的 `data_version` 运行两次相同研究，确认报告与 artifact 的 `manifest_hash` 一致。
5. 演练通过后，再对同一经批准来源进行全 A 股 8 至 10 年回填。

## 不采用的捷径

- 不因数据易得而把前复权、后复权或口径不明日线混入原始表。
- 不让 AKShare、adata 等在线接口承担唯一生产数据源职责。
- 不用 fixture 补全导入失败的真实标的。
- 不修改已经发布的数据版本；供应商修订应形成新的版本并重新验收。
